# Журналы сессий: тест «Танки», Opus 5.5 против GPT-6 Astra

Здесь полные журналы того, что делали агенты в тесте «Танки» из ролика: промпт, все видимые сообщения моделей, каждый вызов инструмента и его результат, время и расход токенов. Обе модели получили один и тот же промпт ([prompts/tank-battle.md](../prompts/tank-battle.md)) и работали каждая в своей папке 25.09.2026.

| Модель | Среда | Время работы | Стоимость | Все токены | Выход |
|---|---|---|---|---|---|
| Opus 5.5 (с тремя подагентами) | Claude Code, effort max | 2:43:16 | $30.96 (из них подагенты $13.84) | 67,7 млн | 416 562 |
| GPT-6 Astra | Codex CLI 0.157.0, effort max | 34:04 | $7.12 | 3,1 млн | 56 365 |

Стоимость посчитана по API-ценам на 25.09.2026; у подагентов по цене их модели.

## Как читать

Начни с `transcript.md`. Время `+чч:мм:сс` отсчитано от промпта; у подагентов тоже от промпта Opus, так что моменты в разных файлах совпадают. Сообщения моделей приведены полностью, вызовы инструментов коротко (команда или файл), результаты усечены до 15 строк. Прогоны песочницы и собственных стендов отмечены строкой **СЧЁТ**. Длинные паузы, когда модель готовила следующий шаг, отмечены отдельно.

`session.jsonl` это исходный журнал, по одной JSON-записи на строку, без усечений: полный код, который писали модели, полный вывод команд, счётчики токенов (`usage` у Claude Code, `token_count` и `token_usage_record` у Codex) и временные метки UTC. Местное время в ролике UTC−3.

## Что убрано

Скрытые рассуждения моделей не публикуются. Из журналов целиком вырезаны блоки рассуждений Claude Code и записи рассуждений Codex вместе с их зашифрованным содержимым; при обработке они отбрасывались по типу записи, их текст не читался. Их объём остаётся виден в счётчиках токенов (у Claude Code поле счётчика рассуждений переименовано в `reasoningTokens`, значения не менялись). Поэтому в расшифровке есть паузы: например, Opus после чтения правил 11,7 минуты готовил первый ход.

Приватное вычищено: личные инструкции и память агентов владельца ПК, списки установленных у него скиллов, плагинов и инструментов, системный промпт Claude Code, e-mail, идентификаторы аккаунтов, имя пользователя Windows (пути вида `C:\Users\...` заменены на `~`), имя компьютера, часовой пояс, адреса и имена серверов, одобренные заранее команды. На месте удалённого стоит пометка. Всё остальное оставлено как было.

Служебная запись `cost-state` в журнале Opus это накопительная оценка самого Claude Code; цифры ролика посчитаны по API-ценам и приведены в таблице выше.

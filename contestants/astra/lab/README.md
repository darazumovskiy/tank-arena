# Песочница ПАРАЛЛАКСА

Все артефакты этой папки служат проверке. Турнирный бот не зависит от них.
`arena/` не изменялась. Официальный соперник неизвестен; дополнительные
соперники построены из доступного «Охотника» и собственной первой версии.

Запуск из корня папки участника:

```powershell
node arena/cli.mjs --rounds 16
node arena/cli.mjs --vs dummy --rounds 8
node arena/cli.mjs --vs tank --rounds 8
node lab/gauntlet.mjs
node lab/stress.mjs
node lab/verify.mjs
```

`gauntlet.mjs` проверяет шесть противников, `stress.mjs` — ещё семь.
Каждый играет восемь раундов: четыре карты, обе стороны. Всего 104 боя.
Последние результаты: `gauntlet-results.json`, `stress-results.json`.
Сводка и SHA-256 сдаваемых файлов: `final-report.json`.

`verify.mjs` проверяет характеристики и диапазоны команд, затем намеренно
отключает огонь у двух экземпляров бота, чтобы проверить весь цикл сужения
зоны и завершение на 120-й секунде. Результат: `verification.json`.

Времена в JSON расширенных серий измерялись при трёх одновременно запущенных
проверках; там есть единичные значения выше 50 мс (максимум 62,9 мс).
Отдельный последовательный прогон штатной CLI дал максимум 4,0 мс и
среднее 0,20–0,25 мс. Это измерения Node.js на этой машине; браузерный
профиль не измерялся. Тексты прогонов: `final-hunter.txt`, `final-dummy.txt`,
`final-mirror.txt`.

`reference-v1/` — неизменённая первая рабочая версия. `opponents/` содержит
подготовленные тестовые варианты. `make-opponents.mjs` воспроизводит их.
`stats-sweep.json`, `tuning-results.json`, `final-tuning-results.json` —
история экспериментов на промежуточных версиях, а не отчёты финального бота.
Файлы `trace-*.json` сохранялись для разбора отдельных боёв разных версий.

`preview.png` показывает реальный рендер SVG, включая независимый поворот
башни и корпус в масштабе 64×64. Для повторного рендера используется
`render-preview.py`, Pillow и установленный только внутри `lab/vendor`
пакет `resvg-py==0.5.0`.

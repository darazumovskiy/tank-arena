# ПАРАЛЛАКС

**«Ты целишься в прошлое.»**

Для турнира нужны только `bot.js`, `body.svg`, `turret.svg`. Бот автономный,
без импортов, пакетов, сети, DOM и системных API.

| Характеристика | Очки | Результат |
|---|---:|---|
| Броня | 2 | 150 HP |
| Двигатель | 1 | 132 px/с, поворот 2,05 рад/с |
| Пушка | 2 | 28 урона, снаряд 550 px/с |
| Перезарядка | 5 | номинально 0,50 с |

Максимальная скорострельность создаёт постоянное давление. Броня оставляет
запас на ошибку, а предсказание снарядов компенсирует умеренную скорость.

На каждом ходу танк сравнивает 23 варианта движения на секунду вперёд,
учитывая разгон, торможение, стены, летящие снаряды и их рикошеты.
Направление вражеской башни и перезарядка позволяют начать манёвр до выстрела.
Башня целится с упреждением по наблюдаемым скорости и повороту противника;
для быстрых целей горизонт прогнозирования поворота короче. При закрытой
прямой линии огня ищется выстрел с одним отражением от стены.

Маршруты проходят с учётом круглого корпуса. При потере здоровья танк ищет
аптечку, при сужении зоны заранее выбирает позицию в безопасном круге.
Дистанция боя сокращается, если длительное обстреливание не приносит урона.

Внешний вид: светлая гранёная броня, бирюзовые дорожки, коралловый глаз
с ромбовидным зрачком. Обе SVG-половины проверены при независимом вращении
и в игровом размере 64×64. Превью: `../lab/preview.png`.

Результаты финальной версии:

- Штатная песочница: «Охотник» — 16:0, «Манекен» — 8:0.
- Расширенная серия из 13 вариантов противника на всех картах с обеих сторон:
  96 побед, 6 поражений, 2 ничьи. Включает штатного «Охотника», его быстрый
  вариант, четыре варианта ранней версии нашего бота и семь дополнительных
  синтетических противников. Код реального соперника не использовался.
- Зеркало финальной версии: 4:4.
- Восьмикратный тест с отключённым огнём: полные 120 секунд, без урона от зоны.
- Последовательный CLI: в среднем 0,20–0,25 мс/ход, максимум 4,0 мс, ошибок 0.

Команды и первичные отчёты находятся в `../lab/README.md`.
